# Instruções para agentes de código

Leia CONTEXTO_PROJETO.md antes de realizar qualquer implementação.

## Regras

- Este é um projeto acadêmico de nível básico.
- Utilize C# e Windows Forms.
- Mantenha compatibilidade com Visual Studio Community.
- Siga MVC básico.
- Priorize código simples, legível e didático.
- Não complique a arquitetura desnecessariamente.
- Não utilize bibliotecas externas sem necessidade.
- Não utilize padrões avançados de arquitetura.
- Não utilize dependency injection.
- Não utilize Entity Framework.
- Não crie interfaces ou abstrações sem necessidade real.
- Não utilize async/await sem necessidade.
- Evite LINQ complexo.
- Utilize nomes claros para classes, métodos e variáveis.
- Faça comentários significativos nas partes importantes da lógica.
- Não faça comentários óbvios apenas para aumentar a quantidade de comentários.
- O aluno deve conseguir explicar todo o código ao professor.
- Preserve a separação básica entre Model, View e Controller.
- O projeto deve continuar compilando após alterações.

## Regra importante

Não tome decisões sobre ambiguidades do enunciado silenciosamente.

Quando um requisito não estiver suficientemente definido em
CONTEXTO_PROJETO.md, apresente a ambiguidade antes de implementar uma
solução arbitrária.
